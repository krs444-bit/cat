# cat
# 🐾 Великий Электронный Питомец (Desktop Cat)

Интерактивный, мемный и невероятно милый котик, который живет прямо на вашем рабочем столе поверх всех открытых окон и программ!

## ✨ Что умеет этот кошак:
* **Гуляет сам по себе:** Кот плавно ходит по экрану поверх браузера, папок и игр без каких-либо квадратных рамок.
* **Смотрит на вас:** Иногда он замирает на месте и утыкается взглядом прямо в экран.
* **Реагирует на мышку («мяу-мяу-мяу»):** Наведите курсор на котика — он немного увеличится и начнет активно перебирать лапками на месте, пытаясь поймать стрелочку.
* **Можно взять на ручки:** Зажмите кота левой кнопкой мыши (ЛКМ) и тащите куда угодно — включится милая анимация, где пушистик зажмурился и поднял лапки вверх.
* **Проявляет любовь (70% шанс):** Каждые 3 минуты котик может внезапно превратиться в милого рыжего шотландца с летающими розовыми сердечками.
* **Имеет свой паспорт:** При запуске на Рабочем столе автоматически создается файл `паспорт_Котик.txt`. 

## 🚀 Как запустить:
1. Скачайте файл **`cat.exe`**.
2. Просто запустите его двойным кликом. Ничего устанавливать не нужно!

## 🛌 Как отправить кота спать:
Нажмите на котика **правой кнопкой мыши (ПКМ)** — откроется панель управления. Нажмите кнопку **«Да»**, и котик уйдет сладко спать на свою мягкую лежанку, а временный текстовый паспорт сам сотрется с Рабочего стола, чтобы не оставлять мусор.
